# Outreach draft

## When to use
Target list is **greenlit** (or user said “just draft”). Prefer a forged amplifier list (Hit-first / P1 / P2) or verified people cards. Default: draft the **Hit first this week** block before the rest. Follow-ups later: max **2** unless asked — this skill is primarily **first touch**.

## Inputs to confirm first
- Greenlit list (or explicit “draft for these N”)
- Start with Hit-first unless user says otherwise
- Channel per target (club email, officer email, Discord, LinkedIn)
- Goal + event hook (title, date, RSVP/Luma link if any)
- Lead voice notes from bot memory (bio, tone) — ask once if missing
- Variants: default **1–2** per target (not 5)

## Draft rules
1. Warm, direct, campus-fluent. Specific over hype. No growth-hack spam.
2. One clear ask (RSVP, 15-min chat, co-host yes/no).
3. Short: LinkedIn/X DM ~500 characters when possible; email can be slightly longer with a tight subject.
4. Personalize with one real detail from their card (club, post, role) — never fake a detail.
5. Label every output **DRAFT — not sent**.

## Process
1. Confirm list + channels.
2. Write drafts. Group by channel if helpful.
3. Show drafts. **Stop.**
4. Send/post/DM **only** if the user gives explicit approval in that turn (e.g. “send the first three”). Otherwise leave as drafts.
5. If they approve sends and you have browser access: send only the approved items, then report status. If you can’t send, hand them copy-paste blocks.

## Report back
For each draft:
- Target name
- Channel
- Subject (if email)
- Body
- Status: `draft` / `sent` (only after approval)

Optional: 2-step follow-up outline (day 3 / day 7) as **drafts**, not scheduled spam.

## Guardrails
- Default is draft-only. No send without explicit yes **in that turn**.
- Do not invent a second list — if the list isn’t approved, send them to `/target-list-forge` or `/linkedin-target-list`.
- No passwords. Browser handoff for LinkedIn/X if sending from the machine.
- Never put private contact lists into a skill you propose to share.
