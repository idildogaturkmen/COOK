# RSVP club loop

> **DEMO / dry-run:** Never publish invites or place paid orders without explicit user approval. Build plans, shortlists, and carts only until the user says go.

Run these in order; do not skip the lock gate.

1. **Plan club event** → concept, intake (incl. **ZIP** + Luma creative inputs), Amazon-vs-local note, invite copy draft.
2. **Luma event invite** → collect **vibes**, **brand assets**, and **language** before opening Luma; one tight browser pass; screenshot; **stop before Publish**.
3. **Lock gate** — wait for explicit approval of final date, headcount, budget, and **event ZIP**.
4. **Amazon event supplies** — quantity math from headcount (1.3–1.5× buffer, show old→new if revising); filters: **>500 reviews**, **tiered ratings** (prefer ≥4.6, else ≥4.5, else ≥4.4), **delivery ≥2 days before event to ZIP**; **Amazon vs local split** (durables on Amazon; milk/ice via Instacart/campus); ASIN shortlist before cart; cart only until approval.
5. **Event food order** — user picks any restaurant/app; headcount + ~10% buffer, dietary split, cost estimate before pay; separate food plan (no default vendor).
6. **Day-of** checklist from the plan skill.

## Cross-account reuse
These skills are plain `SKILL.md` files. Copy the `skills/` tree into another Grok Bot / Cursor account or consume from this GitHub repo so every agent follows the same bars.
