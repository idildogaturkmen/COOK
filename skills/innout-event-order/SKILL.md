# In-N-Out event order

## When to use
Event food should be picked up fresh mid-event (or just before). Keep this **separate** from the Amazon supplies cart.

## Plan to produce
1. **Timing** — order/pickup ~60–75 minutes after doors (or 45 minutes before you want food in-room).
2. **Envoys** — 1–2 people with transport; phones on the sheet.
3. **Default pack** for the headcount (e.g. ~30: mix of cheeseburgers + Double-Doubles + fries; drinks optional if a cafe station covers sips).
4. **Custom order sheet** — columns: name, burger mods, fries, drink, paid?
5. **Logistics blanks** — nearest location, parking, target back-in-room time.
6. **Reimbursement** — photo receipt; club Venmo/card rules.

## Guardrails
- Do not place a real paid order in demo/dry-run mode.
- Collect orders (+ payment method) before the run when possible.
- Keep food staging away from laptops / drink stations.

## Deliverable
A markdown or CSV order plan the organizer can print or share in the club chat, plus a short call-ahead script.
